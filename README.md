# 企业文档云盘系统 (Enterprise Document Cloud Drive) - Backend API

## 项目概述

本项目是一个基于 Spring Boot 构建的企业级文档云盘系统后端服务。系统提供了完整的用户与部门管理、多层级文件目录操作、权限隔离以及基于 AOP 的无侵入式审计日志功能，专为企业内部的数据资产管理设计。

## 核心架构与配置

* **启动与环境**：主启动类为 `FileManageApplication`，默认激活 `local` 运行环境配置。
* **事务与组件**：全局开启事务管理 (`@EnableTransactionManagement`) 保证数据操作的一致性，并通过 `@MapperScan` 扫描持久层接口。
* **定制化装配**：显式排除了默认的 `RedisAutoConfiguration`、`RedisReactiveAutoConfiguration` 和 `SessionAutoConfiguration`，以配合自定义的无状态 Token 鉴权机制。

## 核心模块与功能

### 1. 认证与权限控制 (Auth & Security)

* **无状态登录**：提供用户登录接口，校验通过后颁发访问 Token。
* **账号安全**：支持当前登录用户安全修改个人密码，以及执行登出操作。
* **管理越权拦截**：用户创建、信息编辑、重置密码以及设置离职等高危操作，严格校验当前用户是否具备管理员角色 (`Role == 1`)。
* **三级可见性策略**：底层定义了灵活的权限枚举，支持将资源设置为“私有（0）”、“部门可见（1）”或“全员可见（2）”。

### 2. 用户与员工生命周期 (User Management)

* **核心 CRUD**：支持对系统员工的增加、删除与信息更新。
* **多维检索**：提供基于 `UserSearchReq` 封装的多条件分页查询接口，统一返回 `PageResult` 结构。
* **离职管控**：针对企业场景设计了专门的离职接口 (`/resign`)，支持一键锁定离职员工状态，防止资源越权访问。

### 3. 云盘资源与目录管理 (File & Folder Management)

* **文件夹系统**：支持无限极文件夹的创建、重命名、删除、移动以及拉取指定父节点下的子文件夹列表。
* **细粒度目录权限**：允许对特定文件夹单独调用 `/permission_set/{id}` 接口设置前述的三级可见权限。
* **文件操作闭环**：支持通过 `MultipartFile` 实现文件的挂载上传、重命名、移动目录及删除。
* **高级文件检索**：支持组合“文件名”、“文件类型”、“起始时间”与“结束时间”进行文件记录的精准搜索。

### 4. 统一响应与无侵入日志审计 (Common & Audit)

* **API 标准化**：所有对外暴露的接口均通过 `Result<T>` 泛型类进行包装，统一返回标准状态码 (Code 200/100)、提示信息 (Msg) 及负载数据 (Data)。
* **自定义日志注解**：定义了 `@AutoLog` 注解，用于标记需要审计的操作类型（如“新增用户”）及所属模块。
* **AOP 自动切面**：通过 `LogAspect` 切面实时拦截被 `@AutoLog` 标记的方法，自动记录业务操作的执行情况。
* **全方位溯源**：日志不仅记录操作时间与模块，还能自动提取执行人的 User ID/Name，通过解析 HTTP 请求头精准获取真实的终端 IP，并捕获最多 500 个字符的请求参数和 200 个字符的异常信息落地入库。
